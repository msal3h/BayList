# BayList

A web application for tracking and organizing favorite spots around the Bay Area.

## Features

- Add new places to visit
- Filter by category
- Filter by city
- Mark locations as visited
- Track personal ratings
- Add notes for each location
- Search through saved spots

## Tech Stack

- Next.js 15
- React
- TypeScript
- Tailwind CSS
